# 🎓 Exchange Student Hub

Привет! Это интерактивная база знаний и личный блог, посвященный моему опыту учебы по обмену. 

Этот ресурс создан для того, чтобы помочь студентам пройти весь путь — от мысли *«а не поехать ли мне?»* до успешной сдачи сессии и адаптации в новой стране.

{: .note }
> Используйте поиск вверху страницы (`Cmd + K` или `Ctrl + K`), чтобы быстро найти нужную информацию (например: *виза, жилье, перезачеты*).
